Hex to WIF (offline)

Converts a private key in hex to WIF, compressed and uncompressed, and shows the matching addresses (legacy and SegWit) so you can check the key belongs to the address you expect. Everything runs in this page. It makes no network requests and loads nothing from the internet, so it works with Wi-Fi off.

Leading 0x and leading zeros are optional.

Safety: for a real key, open this file with the network off, and close the tab when done. Don't paste a real key into any website. Before sweeping, check that one of the addresses above matches the address holding the coins, and import the WIF from the same group (compressed or uncompressed). Bitcoin puzzles use the compressed legacy address (1…).

Wallets: one compressed WIF controls all three compressed addresses. Some wallets only look for one kind: in Electrum, type p2wpkh: or p2wpkh-p2sh: before the WIF to find SegWit coins. Bitcoin Cash and Bitcoin SV use Bitcoin's WIF and legacy address. Prefixes are from each coin's own source code (chainparams.cpp).
